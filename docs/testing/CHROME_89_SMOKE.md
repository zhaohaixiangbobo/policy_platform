# Chrome 89浏览器基线冒烟

## 目标

验证一期冻结依赖的生产构建在Chrome 89内核和当前Chrome/Edge中均可完成关键基础交互。
本检查只验证M0/M1工程与组件基线，不代表M2/M3业务验收完成。

## 当前状态

- 2026-08-23：现代Chromium 151生产构建冒烟已通过，详见`MODERN_BROWSER_SMOKE_2026-08-23.md`；
- Chrome 89：由用户在其他机器按本文步骤人工验证，当前不得标记为通过。

## 前置条件

1. Node为`22.23.2`，pnpm为`11.22.0`；
2. 已由用户手动执行`pnpm install`；
3. 已执行`pnpm build`，且`frontend/dist`生成成功；
4. 使用实际Chrome 89或单位实际办公浏览器内核，不使用开发服务器代替生产产物；
5. 分别在1440×900和小于1200px宽度执行检查；
6. 另在当前Chrome或Edge稳定版执行同一组检查。

## 启动生产预览

```powershell
Set-Location 'D:\2-code\policy-platform'
pnpm preview
```

访问`http://127.0.0.1:4173/smoke/browser-baseline`。

## 冒烟步骤

| 编号 | 操作 | 预期结果 |
|---:|---|---|
| 1 | 直接打开冒烟URL并刷新 | 页面正常恢复，无白屏、语法错误或资源404 |
| 2 | 在顶部导航切换首页、智能问答、制度库、服务说明 | URL和选中项同步变化，浏览器前进/后退正常 |
| 3 | 查看表格并缩窄窗口 | 表头和内容可读；必要时横向滚动，不挤压成不可读列 |
| 4 | 点击“打开抽屉”并关闭 | 遮罩、焦点、滚动和关闭按钮正常 |
| 5 | 点击“打开表单弹窗” | Input、Select、确认和取消均可操作 |
| 6 | 检查三状态Tag | ANSWER、资料不足、冲突同时使用文字和颜色区分 |
| 7 | 在Sender输入并提交 | 用户气泡更新并出现“提交事件正常”提示 |
| 8 | 检查助手Bubble | 中文、`[E1]`和气泡布局正常，无溢出 |
| 9 | 点击“PDF入口” | 只出现`document_id`和`page`参数，不出现服务器路径 |
| 10 | 将窗口缩至1200px以下 | 顶部导航变为抽屉入口，主内容仍可使用 |
| 11 | 仅使用键盘完成导航、表单和弹窗操作 | 焦点顺序可见，图标按钮有可读标签 |
| 12 | 打开开发者工具Console | 无未捕获异常、CSS解析错误和不支持API错误 |
