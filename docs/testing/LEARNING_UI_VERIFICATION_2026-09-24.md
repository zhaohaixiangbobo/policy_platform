## 4. 用户手动验收

启动现有前端、API，使用学习模块已启用的账号访问 `/learning`：

1. 配置页搜索、分页、选制度；核对右侧信息、全文/指定条款、题量设置和禁用条件。
2. 有旧检测时生成必须先显示覆盖确认；生成阶段显示后端进度，失败不丢旧检测。
3. 停留本页等待完成，应自动切到答题区；手动切回配置后等待两轮轮询，不应自动跳回。
4. 三种题型选择后，切题和分区再返回，选项应保留；点暂存后刷新，已暂存答案应恢复。
5. 未提交时没有正确答案、对错和原文。提交确认显示未答题数；结果由后端返回。
6. 结果页查看原文、弱项定位、只看错题/未答；全对时正确显示空筛选结果。
7. 新正文版本提示与既有跳转规则保持；过期后显示无有效检测。
8. 检查桌面双栏与窄屏单栏，无长标题、长选项横向溢出。

真实生成会替换最近一次检测，请在允许覆盖的测试账号中进行。未执行真实生成、交卷、模型联调、后端全量测试或压力测试。
