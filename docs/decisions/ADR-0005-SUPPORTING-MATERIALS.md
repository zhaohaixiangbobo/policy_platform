# ADR-0005：配套资料作为Platform独立资源

> 文件说明：补充ADR-0002的数据所有权，不改变制度知识流水线边界。
> 状态：已实施M1—M3；日期：2026-09-25。

配套案例和流程图片不是正式制度文件，第一版不执行制度解析、分块或IndexRun构建。
它们的身份、修订元数据、案例原文、发布状态与导入审计归Platform管理，使用现有SQLAlchemy和Alembic；原图片保存独立持久化目录。
ADR-0002/0004中的知识库边界继续适用于正式制度、解析运行和制度问答。

资料读写统一经过MaterialService，普通用户读取已发布版本，管理员编辑最新草稿。
材料类型使用可扩展字符串和类型字段快照；现阶段只开放CASE/IMAGE，TEMPLATE预留不开放。
不得以资料发布替代制度Alias发布，也不得将案例处理结果当成一般制度规则。

2026-09-26问答已通过独立授权资料接口获取实时辅助推荐，不保存推荐快照、不进入回答生成；见SUPPORTING_MATERIALS_M4.md。学习联动暂缓。如建设向量检索，使用独立资料索引，不混入制度collection。
当前不增加第三数据库；不为了第一版引入消息队列、视觉模型或在线模型整理流水线。
未来MySQL迁移可复用资料ORM和固定迁移脚本，但本轮SQLite验证不代表MySQL已完成验证。
