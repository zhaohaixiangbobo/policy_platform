# 配套资料 v2

> 2026-10-11：字段契约不变，搜索与聊天分流已升级 [material_search_v3](SUPPORTING_MATERIALS_V3.md)，替代下文v2检索策略。

> 文件说明：2026-10-09 当前生效字段与操作契约。版本 supporting_materials_v2 / material_search_v2。

## 图片

只接收资料标题、标签/关键词、简介，三项必填。标题默认文件名并可修改；标题200字，简介10000字，标签20项、每项100字，中英文分号分隔。PNG/JPEG、10MB、2500万像素与受控图片预览/下载保持原有规则。

## 案例 Excel

首表首行依次十列：标题、人员类别、职务/岗位、职级/岗级、政治面貌、涉事年龄、涉及领域、问题性质、处理结果、案情描述。

映射依次为 title、person_category、position、rank、political_status、age、domains、problem_types、outcome、original。标题和案情必填，其他可空。空处理结果存空文本，详情显示“未公布”，不推断结论。五个人员字段按原样文本保留（含多人和真实姓名），各最多1000字。案情最多30000字，处理结果10000字；领域最多10项，问题性质20项，单项100字，只按中英文分号拆分，逗号/顿号保留。

仅上传Excel，不填公共来源信息。表头统一全半角并去空白；数字和日期转文本，44.0变44。公式/错误单元格拒绝。整个文件存在合并区域则提示坐标，需取消合并并补齐，不自动填充。只导入首表；不跳过不完整行。最多200行、10MB、解压30MB。

预览有错误须修正重传；相同案情逐字去重，重复跳过。确认整批事务且幂等，24小时有效且仅创建者可确认。导入为草稿，仍须手动发布。案例其他九字段可编辑，案情只读；原文修改整理后重新导入。

用户提供的样本第26行不完整，按约定删除该行再上传；不为该行新增跳过逻辑。旧七列模板及评测输出不再适用。

## 展示、搜索和权限

图片/案例分别校验，额外字段拒绝。旧来源列保留但写空串，无新迁移。列表移除来源/地区/日期筛选，保留类型、状态、领域、关键词和更新/发布/匹配优先排序。列表和推荐新增顶层 preview_text（案情或图片简介前120字），不传案例全文及处理结果；详情按需读取。案例卡片显示领域和问题性质。

统一 material_search_v2：标题、领域、问题性质或图片标签提供强主题证据；原文只能低权重加分，不能独立触发推荐。处理/处分/监督等泛词不独立触发；兜底领域“其他”“未明确”同样列入泛词，避免条款中“其他部门/其他来源”批量误推荐。独立搜索偏召回，人员字段可用于搜索，但不作推荐强主题。

推荐只读已发布修订；问答每类最多2条，学习提交后每类最多1条。辅助资料不参与答案生成、Citation或评分。权限仍为 material.read / material.manage，平台可见范围不变，不新增脱敏。CSRF、乐观锁、草稿发布隔离及受控附件保持原逻辑。

## 版本切换

用户授权无备份清空旧资料三表和平台对应图片，不删除制度、用户、问答、学习检测、审计、Qdrant或用户原文件。清理前停止后端写入；完成后重启后端、刷新前端、重新导入并手动发布。清理数量和最小测试见 [验证记录](testing/SUPPORTING_MATERIALS_V2_2026-10-09.md)。
