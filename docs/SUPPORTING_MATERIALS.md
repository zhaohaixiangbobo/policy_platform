## 2. 类型和存储边界

`kind` 使用可扩展字符串：当前开放 `CASE`（案例）、`IMAGE`（流程图/图片）。
`TEMPLATE`（模板）在产品契约中保留，当前无上传入口；未来可以扩展 `GUIDE`、`FORM`、`ATTACHMENT`。
后端只接受当前开放类型，不允许任意类型绕过校验。

Platform SQLAlchemy/Alembic新增三表：

- `supporting_material`：稳定ID、类型、原始内容指纹、整体状态、最新/已发布修订指针、乐观锁版本。
- `material_revision`：资料字段与文件信息快照、修订号、状态、确定性检索文本；发布后的内容不覆盖。
- `material_import_batch`：24小时有效预览、创建人、文件名/哈希、逐行校验和确认结果，重复确认幂等。

图片写入 `PLATFORM_MATERIALS_ROOT`，默认 `var/materials`。使用UUID存储文件名、数据库相对键、原文件名和SHA256。
不复制用户原文件、不删除用户原文件、不把文件目录作为静态资源公开。部署时同时持久化Platform数据库和资料目录。
预览只保存原文、结构化内容和来源文件标识，不长期另存整份上传Excel；过期预览拒绝确认，自动清理尚未实现。
不增加第三套数据库，不访问知识库底层表或Qdrant，不接入制度IndexRun/Alias发布机制。
架构补充见[ADR-0005](decisions/ADR-0005-SUPPORTING-MATERIALS.md)。

## 3. 标准七列案例Excel

第一张工作表、第一行表头必须按以下顺序：

| 标题         | 业务领域       | 问题类型 | 标签           | 处理结果           | 案例摘要           | 原文     |
| ------------ | -------------- | -------- | -------------- | ------------------ | ------------------ | -------- |
| 简洁案例名称 | 人事与劳动管理 | 连续旷工 | 旷工；劳动纪律 | 原文明确的处理结果 | 简要描述行为与结果 | 完整原文 |

- 业务领域、问题类型、标签支持多个值，中文或英文分号分隔；单项最多40字。
- 标题和原文为导入必填，其他字段可先为空，发布前需要业务领域和摘要等必要信息。
- 原文由程序逐字保存，不做模型改写；保存草稿时不允许替换原文。不同原文作为新资料导入。
- 最多200行数据、10MB文件；只支持.xlsx。拒绝公式、Excel错误和非文本字段；内部展开大小限制30MB。
- 第一张表之外的工作表不导入，适配评估文件的附加“样本记录”表。
- 不支持本轮之前无表头单列格式；先按已确认的辅助整理路径生成七列、人工核对，再导入。
- 可选填写本批次公共来源单位、来源出处、来源分类、地区、来源/通报日期。来源单位和来源出处留空不影响发布；不要用处分日期代替通报日期，未知日期留空。
- 来源分类：中央纪检监察通报、行业通报、地方通报、其他；与地区分开存储。
- Excel上传后展示新增、重复、错误行和各字段预览。有错误必须修正文件后重传；重复默认跳过，不覆盖已有内容。
- 重复判断为同类型原文逐字哈希；不同空白、标点属于不同文本，本版不做近似去重。
- 预览有效24小时，只有创建预览的管理员可以确认。确认时重新检查数据库重复项，整批事务提交。
- 导入结果是草稿；不会直接公开，也不会自动调用模型或生成向量。

## 4. 图片流程

选择PNG/JPEG → 文件名去扩展名生成标题 → 人工填写字段 → 保存草稿 → 管理员确认发布。
允许修改标题；支持放大、原尺寸查看与拖动（Ant Design Image预览）。后端按真实内容验证格式，不信任后缀；仅静态图片，最多10MB、2500万像素。
原始图片不覆盖，当前版本不提供替换文件操作；更换原始图片作为新资料上传，元数据修改使用修订机制。

公共字段包括：标题、业务领域、简介、标签、适用对象/层级、来源单位、来源出处、来源分类、地区、来源日期。
适用对象不是权限条件。第一版可见范围固定 `PLATFORM`，仅平台内有 `material.read` 权限的用户可读。

## 5. 版本、权限与发布

- USER/REVIEWER/ADMIN拥有 `material.read`；只有ADMIN拥有 `material.manage`。
- 所有写操作校验Cookie会话和CSRF，所有附件地址重复检查资料与版本权限。
- 状态：草稿DRAFT → 已发布PUBLISHED → 已下架OFFLINE。支持下架后重新发布。
- 修改已发布资料时，保存才创建下一修订草稿；仅点击编辑、取消或无改动保存不会生成新修订。
- 修改新草稿不会覆盖普通用户看到的已发布版本。管理员看最新编辑版本并看到“有待发布修订”标识。
- “草稿”筛选包含已有发布版本的新草稿；“已发布”筛选按资料整体状态显示，可能与草稿筛选重叠。
- 发布前要求：标题、业务领域、简介。来源单位、来源出处为选填，允许留空，也可在后续修订中补充或清空；既有草稿无需重新导入。确认对话框提示人工核对与平台可见范围。
- 发布使当前修订生效，原发布修订标为历史版本SUPERSEDED。旧内容保留供管理员只读查看。
- 下架立即阻止普通用户查询详情和读取图片；管理员仍可管理。普通用户不开放历史修订。
- 写操作携带 `expected_version`；冲突409，必须刷新。批量发布/下架整批事务，任何一项失败则全部回滚。
- 保存、发布、下架、导入等写入Platform审计日志，不将长篇案例原文写入审计事件。
- 不提供永久删除接口，避免破坏后续引用追溯。

未来引用资料使用 `material_id + material_revision_id + 标题/来源/原文快照或图片哈希`，不伪装成制度Citation。本轮未改变问答响应。

## 6. 检索与界面

2026-09-26修复未选择日期导致列表422：前端省略空日期参数，错误数组转换为可读文本。已有导入数据无需重新导入，草稿在“草稿”筛选下查看。

搜索范围为标题、业务领域、问题类型、标签、摘要、处理结果和原文等资料字段；多个空格分隔关键词要求同时匹配。
“匹配优先”与问答推荐共用material_search_v1字段评分，详见[M4规则](SUPPORTING_MATERIALS_M4.md)；不等同BM25或语义搜索。
筛选包括类型、业务领域、发布状态、来源分类、地区、来源日期；支持最近更新、最近发布排序，每页10条。
统计在当前搜索及筛选范围内按类型统计，不重复受类型页签限制。管理员可选本页条目批量发布/下架。
图片只搜索人工字段，不理解图片内容。详情展示案例七字段、公共来源、导入行号、修订历史或图片预览。
没有模拟数量、虚构示例卡片或模板功能。
